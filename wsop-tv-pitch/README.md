# WSOP TV 기획 데모 (보고용)

WSOP TV 기획안을 리더·유관 부서에 보고할 때 함께 보여주는 **클릭 가능한 데모**입니다. 실제 개발용이 아니라 서비스 방향과 핵심 경험을 보여주기 위한 것이며, 모든 데이터는 가상입니다.

**기준 문서:** `WSOP_TV_서비스기획안_v1.0` (화면 ID SCR · 홈 구성 HOME · Jira Story ID) · `WSOP_TV_CMS_기획안_요구사항_v1.0.xlsx` (CMS 메뉴 구조도 · 요구사항 ID) · TTN 제안서 V5. 앱의 “기획 포인트 보기” 말풍선과 CMS 화면에 해당 ID를 표시했습니다.

## 실행

```bash
cd wsop-tv-pitch
npm install
npm run dev      # http://localhost:5173 (포트는 Vite가 지정)
npm run build    # 타입 체크 + 정적 빌드 (dist/)
```

- 배포 주소: https://jin9942-cmd.github.io/tv-service/pitch/ (`main`에 push하면 GitHub Actions가 자동 배포)
- 데스크톱 1440px 기준 화면입니다. 화면 폭이 767px 이하(휴대폰)이면 앱 화면만 전체 화면으로 나옵니다.
- 백엔드는 없습니다. 상태는 메모리에만 있어서 **새로고침하면 초기화**됩니다.

## 콘텐츠 3분류 · Bracelet 파이널 테이블 자동 제작

| 분류 | 내용 | 데모 반영 |
| --- | --- | --- |
| ① ESPN 방송 | ESPN이 제작 | 현재 논외 (CMS 설명에만 표기) |
| ② YouTube 방송 | Feature Table, 이번 여름 방식으로 지속 고도화 | 라이브 상세 “Also streaming on the WSOP YouTube channel” |
| ③ WSOP TV 전용 | **모든 Bracelet 파이널 테이블 (연 ~250개)** | 앱 홈 “Only on WSOP TV” 섹션 · 카드 배지 · 편성표 금색 점 · 라이브 상세 안내 |

**③의 목표:** RFID 업체 연동으로 파이널 테이블의 카드·칩 데이터를 EBS가 자동 수신 → AI 카메라·마이크가 화면·오디오를 자동 구성 → AI 해설자가 해설 → **운영자 최대 1명이 연 ~250개 파이널 테이블을 모두 커버.** 1~2년 안에 완성하는 것이 목표이고, 이를 위해 EBS와 WSOP TV 앱 연동 세팅이 전제입니다.

- **CMS › 편성·라이브 › AI 자동 제작 (신규 제안):** 올해 커버 n/250 · 지금 자동 제작 중 테이블 · 운영 인원 1명 · 개입 필요 건수 KPI, 테이블별 파이프라인(RFID → EBS → AI 카메라 → AI 마이크 → AI 해설 → 송출 → Quick VOD) 상태, 1인 관제 알림(수동 샷 지정), 콘텐츠 3분류, 로드맵(RFID 연동 → AI 카메라·마이크 → AI 해설자).
- **앱:** 자동 제작 파이널 테이블은 오디오가 “AI commentary · English / Español / Table sound only”이고, CMS에서 AI 해설을 끄면 현장음만 남습니다. 사람 해설이 없는 구조라 “English commentary” 같은 옵션은 나오지 않습니다.
- 톤 가이드에 따라 앱 화면에는 카드·칩 그래픽을 보여주지 않고, RFID·EBS는 운영(CMS) 설명에만 씁니다.

## 데이터 모델 (`src/data`)

투어 > 시리즈 > 이벤트 > 데이(Flight) > **편성(방송 1건 = 시간 슬롯 × 송출 채널)** → 라이브 → VOD. 선수는 VOD와 N:M.

- 투어 3종, 시리즈 4개(진행 중 1 · 예정 1 · 종료 2), 송출 채널 CH-01~04, 언어 EN/ES/PT
- 편성 19건(진행 중 3건 포함), VOD 24개, 가상 선수 9명, 배너 4 · 띠배너(등급별) · 공지 4(타입 · 상단 고정 · 등급 공지) · 큐레이션 3
- 편성 시각은 **페이지를 연 시각 기준 상대 시각**이라 언제 열어도 라이브가 진행 중입니다.

## 데모 가정

- **구독 비교표는 예시 정책(미확정)입니다.** 무료 등급 운영 여부는 기획안 9장 결정 필요 항목이라, 데모에서는 무료/베이직/프리미엄 3단계로 보여줍니다.
- **로그인·구독·스토어·Transcribe 버튼은 데모 상태만 바꿉니다.** 실제 로그인·결제·영상·DRM·지역 판별은 없습니다.
- **DVR 윈도우(데모 2시간)·Catch-up 보존 기한·미리보기 시간(데모 10초)** 은 TTN 최적안 검토 후 확정할 값입니다.
- **요금제(Plans) 홈 섹션**은 기획안 홈 구성에 없어 기본 숨김입니다(CMS에서 켤 수 있음).
- **범위 확인 필요(scope-confirm):** 광고(SCTE-35 · GAM CSAI)와 라이브 채팅은 데모에 넣지 않았습니다.

## 톤 가이드: 스포츠 중계

내부 지침에 따라 **사행성을 연상시키는 표현은 쓰지 않습니다.** 칩·카드 앞면 같은 카지노 소품, 베팅 용어(Check/Call/Raise/All-in/Fold), 상금 금액을 내세운 제목은 쓰지 않고, 썸네일은 차분한 펠트 배경, 선수 아바타는 이니셜 + 금색 링입니다. 대회 상세의 바이인은 기획안(SCR-07) 항목이라 정보로만 표시합니다.
