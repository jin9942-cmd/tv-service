# WSOP TV 기획 데모 (보고용)

WSOP TV 기획안을 리더·유관 부서에 보고할 때 함께 보여주는 **클릭 가능한 데모**입니다. 실제 개발용이 아니라 서비스 방향과 핵심 경험을 보여주기 위한 것이며, 모든 데이터는 가상입니다.

## 실행

```bash
cd wsop-tv-pitch
npm install
npm run dev      # http://localhost:5173 (포트는 Vite가 지정)
npm run build    # 타입 체크 + 정적 빌드 (dist/)
```

- 배포 주소: https://jin9942-cmd.github.io/tv-service/pitch/ (`main`에 push하면 GitHub Actions가 자동 배포)
- 데스크톱 1440px 기준 화면입니다. 화면 폭이 767px 이하(휴대폰)이면 앱 화면만 전체 화면으로 나옵니다.
- 백엔드는 없습니다. 상태는 메모리에만 있어서 **새로고침하면 초기화**됩니다.

## 구성

상단 탭 **[앱 데모] [CMS 데모]** 가 같은 메모리 상태를 공유합니다. CMS에서 바꾼 내용은 앱 데모에 즉시 반영됩니다(앱 배포 없이 반영되는 구조 시연).

| 영역 | 내용 |
| --- | --- |
| 앱 데모 | 가운데 스마트폰 프레임(390×844 화면), 왼쪽 **시연 시나리오**(각 단계 “준비” 버튼), 오른쪽 **데모 설정** |
| 데모 설정 | 회원 상태(비로그인/무료/베이직/프리미엄) · 운영 모드(시즌/비시즌) · 진행 중 라이브 0건 · **시청 환경(정상/지역 제한/VPN 감지)** · **구독 만료** · 표시 시간대(Seoul/Los Angeles) · 기획 포인트 보기 |
| 앱 화면 (영문 UI) | 홈, 라이브 플레이어, 편성표, VOD/VOD 상세, 대회/대회 상세, 선수 상세, 통합 검색, 구독 안내(페이월), MY·알림함 |
| CMS 데모 (한글 UI) | 전체 메뉴 트리 + 동작 화면 4개: 운영 현황 대시보드 · 편성표(타임라인) · 메인 화면 관리 · **포커 용어 사전**. 나머지 메뉴는 “데모 범위 외” |

## 완료 기준 시나리오 (모두 클릭으로 진행)

1. 비로그인 → 홈 → LIVE NOW 카드 → 로그인 유도 바텀시트
2. 무료 → Premium 라이브 → 10초 미리보기 → 구독 안내 → Premium 구독 → 바로 시청
3. Premium → 라이브 → “Feature Table ES” 칩으로 전환 → Up next에서 알림 신청
4. 데모 설정 시즌 → 비시즌 → LIVE NOW 사라지고 이어보기·큐레이션 VOD가 배너 아래로
5. 라이브 0건 ON → LIVE NOW 대신 “Next live in” 카운트다운
6. CMS › 메인 화면 관리 → 순서 변경/숨김 → 저장 → 앱 홈 즉시 반영
7. CMS › 편성표 → + 편성 등록 → 저장 → “라이브 자동 생성됨” → 앱 편성표·홈 “Schedule”에 New 표시로 반영
8. 표시 시간대 변경 → 앱 안의 모든 시각 변환
9. (추가) 비로그인 → VOD 상세 “+ My List” → 로그인 유도 → 로그인하면 바로 저장 → MY 탭 My List / See all에서 확인·삭제
10. (제안서) Premium → 라이브 → 일시정지·10초 되감기 → “−0:12 · Go Live”로 복귀 → CC에서 AI 자막·오디오 트랙 선택
11. (제안서) 시청 환경 VPN 감지 → 라이브 진입 시 차단 안내 → “I'm travelling”(여행자 인증) → 시청
12. (제안서) 구독 만료 → 하단 갱신 안내 · 무료로 전환되어 Premium 라이브는 미리보기 → Renew → 바로 시청
13. (제안서) 이어보기 Edit → 개별 삭제(홈) / 개별·전체 삭제(MY)
14. (제안서) CMS › 포커 용어 사전 → 대기 용어 “사전 배포” → 자막 미리보기와 앱 플레이어 CC › English (AI) 자막이 교정됨

## 데이터 모델 (`src/data`)

투어 > 시리즈 > 이벤트 > 데이(Flight) > **편성(방송 1건 = 시간 슬롯 × 송출 채널)** → 라이브 → VOD. 선수는 VOD와 N:M.

- 투어 3종(BRACELETS / SUPER CIRCUIT / CIRCUIT), 시리즈 4개(진행 중 1 · 예정 1 · 종료 2), 시리즈별 이벤트 4~6개와 데이
- 송출 채널 CH-01~04, 언어 EN/ES/PT
- 편성 19건: 오늘 진행 중 3건(같은 이벤트의 EN/ES 방송 포함), 예정, 종료(다시보기 VOD 연결), 시간 변경(Changed) 1건, 어제·내일·모레
- VOD 24개(Full Replay / Highlight / Clip / Hand / Interview / Shorts, 등급 혼합), 가상 선수 9명, 배너 4 · 띠배너(등급별) · 공지 3 · 큐레이션 3
- 편성 시각은 **페이지를 연 시각 기준 상대 시각**이라 언제 열어도 라이브가 진행 중입니다.

## 데모 가정

- **회원 등급 접근:** 비로그인은 재생 시 로그인 유도. 등급이 부족하면 10초 미리보기 후 구독 안내. 모든 카드에 Free/Basic/Premium 뱃지.
- **구독 안내 비교표는 예시 정책(미확정)입니다.** Free: 무료 콘텐츠·광고·720p / Basic: 베이직까지·프리롤만·1080p / Premium: 전체·광고 없음·1080p 이상. 가격은 TBD.
- **로그인·구독 버튼은 데모 회원 상태만 바꿉니다.** 실제 로그인·결제·영상 재생은 없습니다. 플레이어는 썸네일과 컨트롤 UI만 있습니다.
- **라이브 0건 시뮬레이션:** 오늘 첫 라이브 직전 시각으로 데모 시계를 옮깁니다. 그래서 홈·편성표·CMS가 모두 “아직 시작 전”으로 일관되게 보입니다.
- **홈 요금제(Plans) 섹션:** Free/Basic/Premium 카드(예시 정책)를 홈에 노출합니다. 기본 노출 대상은 비로그인·무료·베이직이고(프리미엄은 숨김), 현재 요금제는 “Your plan”으로 표시됩니다. 대상 등급·순서는 CMS 메인 화면 관리에서 바꿉니다. 쇼츠·인기 영상(Top 10) 홈 섹션은 제외했습니다(쇼츠 영상은 VOD 탭 유형 필터에 남아 있음).
- **My List(즐겨찾기):** VOD 상세 “+ My List”, 선수 상세 “☆ Favorite”, 대회 상세 “☆ Save”로 저장합니다. MY 탭 상단에 최근 4개와 “See all”(전체 목록 · All/Videos/Players/Tournaments 필터 · 개별 삭제)이 있습니다. 비로그인은 로그인 안내 후 바로 저장됩니다. 데모 시작 시 예시 항목 2개가 들어 있습니다.
- **홈 섹션 숨김:** 섹션에 보여줄 데이터가 없으면 섹션 자체가 숨겨집니다(예: 비로그인의 이어보기).
- **홈 구성 세트:** CMS 메인 화면 관리에서 시즌/비시즌 세트를 각각 편집·저장하고, “이 구성으로 운영 적용”으로 운영 모드를 바꿉니다.
- **썸네일:** 외부 이미지 없이 그라데이션과 텍스트만 씁니다. 로고는 텍스트 워드마크이고, 공식 자산은 쓰지 않았습니다.

## TTN 제안서(V5) 반영 사항

제안서(Poker Streaming Platform, V5)의 기능 범위와 맞추기 위해 다음을 데모에 넣었습니다.

| 제안서 항목 | 데모 반영 |
| --- | --- |
| DVR & Live Rewind | 라이브 플레이어: 일시정지 시 라이브와의 차이 누적, 10초 되감기/앞으로, 2시간 DVR 윈도, “Go Live” 복귀 |
| ABR · 화질 선택 | 화질 목록 1080p60 ~ 240p (등급별 최대 화질은 예시 정책) |
| 다국어 자막 · 오디오 트랙 | CC 메뉴: AI 자막(EN/ES/PT/KO) · 오디오(해설 언어 / 현장음만) |
| Poker Vocabulary Manager (V5 추가) | CMS › 자막/AI › 포커 용어 사전: 용어·발음 표기·자막 표기 등록 → 배포 → 앱 자막 교정 |
| Continue Watching 수동 삭제 (V5 추가) | 홈 이어보기 Edit · MY 이어보기 개별/전체 삭제 |
| Independent Watchlist (V5 추가) | My List는 이어보기와 별개 목록으로 유지 (VOD · 선수 · 대회) |
| Geo-fencing / Blackout · VPN 감지 · 여행자 지원 | 데모 설정 “시청 환경”: 지역 제한은 라이브만 차단(VOD 시청 가능), VPN 감지는 전체 차단 + 여행자 인증 |
| WSOP+ 권한 만료 처리 | 데모 설정 “구독 만료”: 강제 차단 대신 무료로 전환 + 갱신 안내(Renew) |
| 콘텐츠 메타데이터 (대회 · 테이블 · 핸드 · 선수 · 주요 장면) | VOD 상세 “Key moments” + 재생 바 마커, 탭하면 해당 위치로 이동 |
| CMS 범위 (핸드/하이라이트, 지역 권리) | 메뉴 트리에 “핸드 · 주요 장면 태깅”, “지역 제한 · 블랙아웃”, “자막 · 오디오 트랙” 추가 (범위 외 표시) |

**의도적으로 넣지 않은 것:** 제안서 예시 화면의 “PLAY POKER / TAKE YOUR SEAT” 프로모션 배너, 바이인·상금 보장액($) 강조 문구는 사행성 최소화 지침에 따라 넣지 않았습니다. 10개 엔드포인트(PC Web, iOS, Android, 스마트 TV 등)와 Multi-DRM, QoS 분석은 화면으로 보여줄 대상이 아니라서 데모에서는 다루지 않습니다.

## 화면 정리 원칙 (산만함 줄이기)

- 홈 섹션 제목은 “Schedule”처럼 짧게 씁니다.
- 썸네일 위에는 신호 1~2개만 둡니다(LIVE · 등급 · 재생 시간/시청자). 제목은 썸네일 아래에만 쓰고, 썸네일 안 중복 문구와 잠금 아이콘은 뺐습니다(등급 뱃지로 충분).
- 스케줄 행은 상태 표시를 하나만 씁니다: 진행 중은 LIVE, 예정은 Remind 버튼, 종료는 Replay 글자. 송출 채널 코드(CH-xx)는 운영 정보라 앱에서 뺐습니다.
- 이벤트명에서 상금 보장액(GTD)을 빼고 “Main Event · Day 2”처럼 줄였습니다.
- 홈 기본 구성에서 띠배너·공지는 숨김(CMS에서 켤 수 있음), 큐레이션은 최대 2줄입니다.
- 등급 뱃지는 채움색 대신 외곽선 위주의 차분한 색을 씁니다.

## 톤 가이드: 스포츠 중계

내부 지침에 따라 **사행성을 연상시키는 표현은 쓰지 않습니다.** 포커를 카지노 게임이 아니라 스포츠 중계로 보여주는 것이 원칙입니다.

- **썸네일:** 중계 현장(피처 테이블 세트)을 위에서 본 차분한 펠트 배경과 스튜디오 조명만 씁니다. 칩, 카드 앞면, 카드 랭크 같은 카지노 소품은 쓰지 않습니다.
- **선수 아바타:** 이니셜과 얇은 금색 링(브레이슬릿·트로피 연상)만 씁니다. 칩 모양은 쓰지 않습니다.
- **문구:** 베팅 용어(Check/Call/Raise/All-in/Fold)는 쓰지 않습니다. My List, Remind, Subscribe, Not now, Continue Watching처럼 일반 OTT 용어를 씁니다.
- 한때 넣었던 포커 아이덴티티(칩 아바타, 카드 프레임, 액션 키워드)는 이 지침에 따라 제거했습니다.

## 범위 제외

멀티뷰, 라이브 채팅, 실제 결제/로그인 화면, 실제 자막 생성(STT)·DRM·지역 판별, 다국어 번역, CMS 4개 화면 외 기능.
